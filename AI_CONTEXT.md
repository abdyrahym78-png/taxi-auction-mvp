# SAYT X TAXI - AI Context & Project State
## 🎯 Цель проекта
MVP для прямого связывания пассажиров и водителей в Туркменистане без комиссий, балансов и встроенных платежей.
## 🛠 Стек технологий
- **Frontend:** React, TypeScript, Vite, TailwindCSS, Leaflet (OpenStreetMap).
- **Backend:** Node.js, Express.
- **Хранение:** Файловая БД (`data/db.json`), логи (`logs/app.log`).
- **Среда:** Termux (Android), GitHub (`abdyrahym78-png/taxi-auction-mvp`).

## 🌐 Мультиязычность
Поддерживается русский (`ru`) и туркменский (`tm`) языки с динамическим переключением и сохранением выбора в `localStorage`.
